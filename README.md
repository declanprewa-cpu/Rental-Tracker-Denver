# Denver rental tracker

A shared rental shortlist with a focused neighborhood map and rent split for three people.

## Updating

The site is in `index.html`. Edit it on GitHub or ask Codex to add a listing or update details, then commit to `main`. GitHub Pages automatically publishes changes. Friends can view the public site without an account; editing the published version requires repository write access.

Listing prices and availability are manually maintained. The initial listing was captured September 29, 2026. Rent per person excludes utilities and optional fees.

The map uses the official OpenStreetMap embed. Its marker is an approximate street-address location from the U.S. Census Geocoder, not an exact unit entrance.
